# Laboration 4 | Backendbaserad webbutveckling
I denna uppgift så har vi fått träna på att göra autentiseringar för att kunna nå skyddade routes i vår webbtjänst. 
I detta fall har jag skapat en webbplats där man kan se olika produkter på startsidan, med möjlighet att registrera och logga in för att komma åt en adminsida. 
På adminsidan kan man få ytterliggare information om produkterna som man inte ser när man inte är inloggad. Man har även möjlighet att lägga till och radera produkter.
